# Significance tests of the main claims (EMSE revision, R3 / Editor)

Generated by `results_analysis/significance_tests.py` (deterministic, seed 20251029). The LaTeX rows of Table 10 in the paper are generated from `results.csv` by `results_analysis/significance_table.py` (`table.tex`).

## Goal
Test whether the differences behind the paper's main comparative claims are statistically significant.
- `claims.csv` lists the claims: quote, file:line, the compared pair, and the metrics.
- `results.csv` has all tests, at full precision.

## Method (as reported in the paper, Section 3.6)
- **Paired bootstrap over issues.** The 356 CV issues (326 for the temporal evaluation) are resampled with replacement, B = 10,000.
  - Δ = metric(A) − metric(B), computed on the pooled comments of each resample.
  - We report the 95% percentile CI and a two-sided p = 2·min(P(Δ≤0), P(Δ≥0)), floored at 1/B.
  - This test is used for all claims, including the ML configuration claims of RQ1.
  - The same resamples are used for all claims of a setting (common random numbers).
- **Holm correction** within each RQ family (RQ1, RQ2, RQ3, RQ4, Temporal) and metric (P, R, and F1 are separate questions).
  - With B = 10,000 and up to 10 tests per group, Holm-adjusted p-values cannot be resolved below about 0.001.
  - Table 10 therefore shows such values as "≤0.001".
- **Pooled metrics.** Metrics are pooled over comments, as in the paper.
  - Prompting: the counts of the 3 executions are summed, which is the same as averaging them, as in Table 5.
  - "Average of the six models" is the mean of the six pooled per-model scores, computed in each resample.
- **Secondary test (not reported in the paper).** `results.csv` also has a fold-level Wilcoxon signed-rank test (`wilcoxon_*` columns).
  - It has low power: with 10 folds, the smallest p is 0.002.
  - The fold scores are not independent, because the training sets overlap.

## Main findings (see `table.tex` / Table 10 for all values)
- **RQ1.**
  - With Llama embeddings (no data balancing), F1 improves significantly over TF-IDF for SVM, LR, and KNN, and drops for RF and DT (p ≤ 0.001). NB shows no difference (p = 0.900).
  - SVM vs LR: ΔF1 = +0.026, 95% CI [0.006, 0.045], p = 0.025.
- **RQ2.**
  - The prompting strategies do not differ in F1 (p ≥ 0.532).
  - The issue description lowers F1 for all three strategies (p < 0.005).
  - Prompting vs SVM: ΔF1 = −0.147.
- **RQ3.**
  - Llama-3ft vs RoBERTa: recall +0.126 and precision −0.048 are significant, but F1 +0.024 is not (p = 0.116).
  - Llama-3ft vs SVM: F1 +0.053 (p = 0.002).
  - RoBERTa vs SVM: F1 not significant (p = 0.068).
  - RoBERTa vs BERT: not significant. RoBERTa vs XLNet and DistilBERT: significant.
- **RQ4.** Best ensemble vs Llama-3ft: F1 +0.021, small but significant (p = 0.041), from precision +0.077.
- **Temporal evaluation.**
  - RoBERTa beats Llama-3ft (F1 +0.061) and SVM (+0.078).
  - Llama-3ft vs SVM: not significant (p = 0.456).
  - All three models drop from cross-validation to temporal evaluation (p ≤ 0.001).

## Caveats
- The bootstrap keeps the trained models fixed. It does not capture the variance from retraining, e.g., random initialization (stated in Section 6 of the paper).
- RoBERTa vs DistilBERT uses the DistilBERT column of `ensembled_models.xlsx`, which is DistilBERT without data balancing (0.681/0.641/0.660).
